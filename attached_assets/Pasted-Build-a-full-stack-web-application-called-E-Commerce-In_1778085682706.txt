====================================================
🗄️ DATABASE REQUIREMENTS (VERY IMPORTANT)
====================================================

Use MySQL database named:
ecommerce_inventory_system

Create these tables:

1. customers
- customer_id (Primary Key)
- name
- email
- phone
- address

2. products
- product_id (Primary Key)
- product_name
- category
- price
- stock_quantity
- description

3. orders
- order_id (Primary Key)
- customer_id (Foreign Key)
- order_date
- total_amount
- status

4. order_details
- order_detail_id (Primary Key)
- order_id (Foreign Key)
- product_id (Foreign Key)
- quantity
- subtotal

5. inventory_logs
- log_id (Primary Key)
- product_id (Foreign Key)
- stock_before
- stock_after
- updated_at
